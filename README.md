# 🌐 FlowPDV — Site Oficial & Landing Page (www.flowpdv.com.br)

> **Site institucional e comercial de alta conversão para divulgação do FlowPDV.**

---

## 📌 1. Visão Geral
* **Domínio Oficial:** `https://www.flowpdv.com.br`
* **Deploy:** Vercel conectado à branch `main` deste repositório (`DouglasNico/flowpdv-site`).
* **Objetivo:** Apresentação da proposta de valor, recursos da Frente de Caixa e Gestão, Curva ABC, Caderneta de Fiado com WhatsApp, App do Dono no celular, comparativo com sistemas lentos e captação de clientes via WhatsApp.

---

## 📂 2. Estrutura de Arquivos
* `index.html`: Layout semântico, otimizado para SEO com OpenGraph e showcase interativo de telas.
* `style.css`: Design System Dark Glassmorphic, tipografia Plus Jakarta Sans e regras de escalonamento OS (125%/150%).
* `assets/`: Logotipos e capturas reais das telas do sistema (PDV, Estoque, Curva ABC, Auditoria).
